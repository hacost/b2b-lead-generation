# reports/

Reportes generados por las fases de auditoría (ver ASDP-PROCESS.md):
`quality-report.md` (Fase 6), `security-report.md` (Fase 7),
`iteration-close.md` (Fase 8), `release-report.md` (Fase 9, solo cuando un
incremento sube a producción). Se nombran por iteración cuando hay más de una
en paralelo.
