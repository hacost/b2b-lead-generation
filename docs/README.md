# docs/

Referencias extensas y específicas de un módulo o tema que no pertenecen a
`CLAUDE.md` (ver ASDP-PROCESS.md, "Los prompts como slash commands"). Cada
prompt de fase referencia aquí solo el archivo que realmente necesita — no se
carga todo `docs/` en cada sesión.

Vacío por ahora: no hay ninguna iteración todavía que haya necesitado un
documento de referencia dedicado.
